Mesh Uploader (FBX Only)Upload FBX dari GitHub ke akun Roblox

Isi enam kolom di bawah, lalu tekan Create Mesh. API Key hanya dipakai di browser ini dan tidak disimpan.

Cara bikin API Key
  1. Buka Creator Hub, masuk ke Open Cloud, lalu API Keys.
  2. Buat key baru seperti biasa, beri nama bebas.
  3. Di Access Permissions, tambah Assets, lalu centang operasi Read dan Write.
  4. Supaya mesh otomatis publik, tambah juga Asset Permissions dengan operasi Write.
  5. Di Security, isi IP dengan 0.0.0.0/0 karena HP punya IP yang berubah.
  6. Simpan, lalu salin key-nya dan paste di kolom ini.
Cara siapkan link GitHub
  1. Buka GitHub.
  2. Buat repository dengan visibilitas Public dan aktifkan Add a README file.
  3. Buat commit yang isinya upload file FBX mesh (Add file, Upload files, Commit changes).
  4. Setelah commit, buka file FBX di repository, lalu salin permalink dari menu titik tiga.
  5. Paste link tersebut di kolom ini.

User ID adalah akun pemilik key. Angkanya ada di link profil Roblox kamu.

Pengaturan lanjutan (Worker proxy)

Isi hanya kalau Create Mesh gagal dengan pesan koneksi ditolak. Kosongkan untuk langsung ke Roblox.
